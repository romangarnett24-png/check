# История действий по разработке проекта AI Text Improver

В данном логе зафиксированы все этапы разработки расширения Google Chrome.

---

### 📅 Этап 1: Инициализация и проектирование (17.07.2026)
* **Анализ требований**: Сформулирован сценарий работы (User Flow), аналогичный AI-асситенту Telegram, адаптированный под браузер.
* **Выбор архитектурных решений**:
  * Использование **Shadow DOM** для отрисовки виджетов. Это гарантирует, что стили страницы-хоста не сломают разметку расширения, а стили расширения не затронут страницу.
  * Выполнение запросов к OpenRouter через **background-скрипт (Service Worker)** для обхода политики CORS.
  * Использование стандартных элементов ввода `<input type="text">` и `<textarea>`.
* **Выбор дизайна**: Утвержден стиль **Sleek Dark Mode** с использованием размытия (`backdrop-filter`) и фиолетово-синих градиентов для кнопок.

### 📂 Этап 2: Создание структуры и написание кода (17.07.2026)
1. **Разработка `manifest.json`**:
   * Создан манифест стандарта **Manifest V3**.
   * Запрошены разрешения на домен `https://openrouter.ai/*`.
   * Настроены пути для скрипта контента (`content.js`) и фонового сервис-воркера (`background.js`).
   * В раздел `web_accessible_resources` внесен файл `styles.css`.
2. **Разработка `background.js`**:
   * Был зашит API-ключ OpenRouter (позднее заменен на заглушку `YOUR_API_KEY_HERE` для безопасности).
   * Настроен массив бесплатных fallback-моделей: `google/gemini-2.5-flash:free`, `meta-llama/llama-3-8b-instruct:free`, `mistralai/mistral-7b-instruct:free`.
   * Добавлен слушатель сообщений `chrome.runtime.onMessage.addListener` с поддержкой асинхронных ответов.
   * Написана функция `callOpenRouter`, формирующая POST-запрос с заголовками идентификации расширения.
3. **Разработка `content.js`**:
   * Реализовано глобальное отслеживание последнего активного поля ввода через событие `focusin`.
   * Настроена функция `getSelectionDetails()`, проверяющая как стандартный текст на странице, так и выделение внутри инпутов/textarea.
   * Добавлены слушатели событий `mouseup` и `keyup` для своевременного показа меню (Tooltip 1) и закрытия при деактивации выделения.
   * Реализовано вычисление координат виджета с учетом текущей прокрутки страницы.
4. **Разработка `styles.css`**:
   * Заданы базовые правила сброса через псевдокласс `:host` для Shadow DOM.
   * Описан класс `.ai-improver-tooltip` с полупрозрачным фоном, скруглениями углов в 12px, размытием подложки `blur(14px)` и тенью.
   * Заданы стили для кнопок, переходов при наведении и нажатии.
   * Добавлены анимация плавного появления виджета и анимация вращения `ai-spin`.

### 🔧 Этап 4: Рефакторинг и исправление ошибок по рабочему образцу (17.07.2026)
* **Проблема**: При нажатии на кнопки виджета выделение в стандартном текстовом поле пропадало (вызывалось событие `blur`), из-за чего меню скрывалось до того, как сработает клик.
* **Решение на основе предоставленного образца**:
  * Реализовано обнаружение выделения через **поллинг** (`setInterval(pollSelection, 200)`). Это обеспечивает 100% стабильность работы во всех браузерах.
  * Реализован глобальный объект `state` для удержания параметров выделения (начальный, конечный индекс, текст) на момент клика.
  * Добавлен перехват кликов через `e.stopPropagation()` на кнопках меню для предотвращения нежелательных действий.
  * Добавлена полная поддержка для сложных редакторов (`contenteditable`), таких как Notion, Gmail и др.
  * Добавлена возможность выделять обычный текст на странице. При нажатии «Применить» текст вставляется в последнее фокусное поле, а при его отсутствии — заменяется прямо в тексте страницы.
  * Внедрены стили Sleek Dark Mode непосредственно в тег `<style>` внутри Shadow DOM для моментального рендеринга без lag-эффекта.
  * Синхронизирован протокол общения контент-скрипта и background-воркера по событию `ai-request`.
  * **Исправление бага мигания**: Обнаружено, что панель ошибок (`panelError`) скрывалась мгновенно через 200мс из-за того, что поллинг `pollSelection` не содержал её проверку во избежание сброса виджета. В проверку `pollSelection` добавлен флаг ошибки, что позволило удерживать окно ошибки на экране в течение 4 секунд.
  * **Предотвращение сброса фокуса (onmousedown preventDefault)**: Добавлены обработчики `onmousedown = (e) => { e.preventDefault(); e.stopPropagation(); }` для всех кнопок виджета. Это предотвращает снятие выделения текста браузером при нажатии на кнопки, гарантируя прохождение клика и вызова API.
  * **Полноценная фильтрация кликов через composedPath**: Обновлена фильтрация кликов в `document.onmousedown` на использование `e.composedPath()`, что надежно предотвращает ложные скрытия виджета при кликах на кнопки внутри Shadow DOM или внутри редактируемого поля.
  * **Добавлено логирование**: Добавлены подробные выводы `console.log` и `console.error` в `content.js` and `background.js` для удобства отладки ошибок сети и API OpenRouter.
  * **Переход на универсальный бесплатный роутер**: В связи с отключением бесплатной модели Gemini (`google/gemini-2.5-flash:free` на OpenRouter) и выдачей ошибки доступности, массив бесплатных моделей `FALLBACK_MODELS` в `background.js` был обновлен. В качестве приоритетного роутера установлен `openrouter/free` (который динамически подбирает активные бесплатные модели), а в качестве резервных добавлены стабильные бесплатные модели `meta-llama/llama-3-8b-instruct:free` и `qwen/qwen-2.5-72b-instruct:free`.
